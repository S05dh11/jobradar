# 任务书：报告页「复制为岗位表格」按钮

## 背景

JobRadar 报告页的数据要能一键复制成表格文本，粘进豆包工作（或任何文档/表格工具）直接用——让「Agent 调研产出 → 办公工具加工」这条链对读者可见、可照做。目前只有脚本 `scripts/export-jobs.mjs` 能导出，链路藏在命令行里。

## 设计

- **位置**：报告页工具区（统计仪表条附近），按钮文案「复制岗位表格」。
- **行为**：纯前端把当前报告的全部岗位拼成 **Markdown 表格**写入剪贴板；成功后按钮瞬时反馈「已复制 N 个岗位」，2 秒后复原。
- **列**（与 export-jobs.mjs 的字段对齐）：公司 / 岗位 / 城市 / 薪资 / 硬性要求 / 核心技能 / 可信度 / 来源URL。缺省字段写「-」。
- **兜底**：`navigator.clipboard` 不可用或失败时，降级 textarea + execCommand，再不行弹提示让用户手动选择页面文本。
- **数据源**：报告页当前 state 里的岗位数组，不重新请求。

## 约束

- **纯前端实现**，不动任何 API / lib；
- **不得破坏 ui-test.mjs 锚点**：新增按钮不得改动既有文案与结构（配置页按钮文案、`border-cyan`、报告页判定词「技能要求词频」、`<article>` 卡片、📍/「必须:」/高/中/低可信文案全部原样）；
- UI 沿用「磷光指挥台」主题 token（globals.css），按钮与现有操作按钮风格一致。

## 验收

1. `npm run build` 通过；
2. 不发真实模型调用、不耗搜索配额；
3. 开发记录写到 `F:\——文章撰写——\火山\seed-dev\开发记录-复制按钮.md`（改动文件、设计决策、自测结果、遗留问题）。
