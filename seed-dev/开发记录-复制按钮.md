## 设计决策

1. **位置**:统计仪表条(四块计数)正下方、右对齐的独立工具行。不嵌入任何既有 section,既有 DOM 结构零变动,对 `ui-test.mjs` 锚点零影响。
2. **数据源**:直接用报告页 state 传入的 `props.jobs`(**全量岗位**),不重新请求;不受分类 tab(`visible`)过滤影响——任务书要求"全部岗位",实测切到「测试」分类后复制仍是全量。
3. **列**:公司 / 岗位 / 城市 / 薪资 / 硬性要求 / 核心技能 / 可信度 / 来源URL,字段集合与 `scripts/export-jobs.mjs` 对齐;数组用「、」连接(与该脚本一致)。
4. **可信度用中文标签**:导出脚本里写的是 `high/medium/low` 原始值,本按钮输出「高可信/中可信/低可信」(`CREDIBILITY_LABEL`,与页面徽章一致)。产物是给豆包工作/文档的粘贴文本,中文标签对读者更可用;"字段对齐"按字段集合而非字面值理解。
5. **缺省值**:`null/undefined/空串/空数组` → 「-」;「未披露」是模型给的显式薪资值,**保留原文**,不当缺省处理。
6. **Markdown 防破表**:单元格内 `|` 转义为 `\|`,换行压平为空格。
7. **三级兜底**(按任务书):
   1. `navigator.clipboard.writeText`(安全上下文,可用时优先);
   2. 不可用或抛错 → 离屏 textarea + `document.execCommand("copy")`;
   3. 仍失败 → `window.alert` 提示"浏览器拒绝了剪贴板访问,请手动选择页面上的岗位文本复制"。
8. **反馈与计时**:成功后按钮文案变「已复制 N 个岗位」,2000ms 复原;连点会清掉旧定时器;组件卸载清定时器。
9. **样式**:复用 `btn-primary` 与「再来一次」完全相同的尺寸类(`!px-4 !py-1.5 text-sm` + 图标),磷光指挥台主题 token,无新增 CSS。

方式:临时把完整 `ReportView` 挂到开发夹具页 `/dev-report`(11 条虚构岗位,含硬性要求/📍地点/竖线转义/低可信/薪资空/技能空/URL 缺省等边界),用与 `scripts/ui-test.mjs` 同款 CDP 驱动本机 headless Edge 跑断言,**无模型调用、无搜索配额消耗**,测完夹具已回滚。

覆盖:

- **锚点不破坏**:「技能要求词频」、📍、「必须:」、高/中/低可信文案、`<article>` 卡片数、配置页「开始调研」、`border-cyan` 选中态全部原样;配置页不出现复制按钮。

- **反馈**:点击后即显「已复制 11 个岗位」,2.3 秒后复原为「复制岗位表格」。
- **全量不随过滤变**:切到「测试」分类(页面只剩 2 张卡),复制内容与计数仍是全量 11 个岗位。
- **execCommand 兜底**:令 `writeText` reject,代码改走 textarea 路径;捕获到的 textarea 内容即同一张全量表,反馈正常。
- **三级失败**:令两层都失败,alert 被触发且文案含"手动选择页面文本"提示,按钮文案不变。

环境事实:headless Edge 中页面无焦点,Clipboard API 会以 "Document is not focused" reject、`execCommand` 返回 false——恰好是第三级 alert 的真实触发场景;测试通过 CDP `Emulation.setFocusEmulationEnabled` 让主路径真实 resolve,内容用 spy 捕获入参断言。
